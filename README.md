# 人間っぽいAI、AIっぽい人間!? — HTMLスライド

24枚構成のHTMLプレゼンテーションです。

## GitHub Pagesで公開する

1. このリポジトリの **Settings** を開く
2. 左側の **Pages** を開く
3. **Build and deployment** の **Source** を `Deploy from a branch` にする
4. Branch を `main`、Folder を `/ (root)` にして **Save**
5. 公開処理が完了すると、次のURLで閲覧できます。

https://rufus505.github.io/ai.html/

## 操作方法

- `→` / `Space` / `PageDown`：次のスライド
- `←` / `PageUp`：前のスライド
- `Home` / `End`：最初 / 最後のスライド
- `F)：全画面表示
- スマートフォン・タブレット：左右スワイプ

## 補足

- 外部ライブラリ不要の単一HTMLです。
- 研究のまとめ・今後の展望の一部は、元資料に具体的な記述がないため補助的な文章として構成しています。
- 文字種・記号比率の図は元資料掲載図の概形を再構成したもので、正確な数値データではありません。
